# Janardhan Builds

Portfolio hub for Janardhan K S.

## Add real project screenshots
Replace the SVG files in `assets/` with screenshots using the same filenames (PNG/JPG), then update the corresponding `image:` path in `projects.js`.

## Add project links
Edit `projects.js` and fill `live:` and `github:` for each project.

## Deploy
Push these files to the `janardhanks/janardhan-builds` GitHub Pages repository.
